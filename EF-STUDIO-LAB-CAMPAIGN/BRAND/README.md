# EF Studio Lab — brand lock

## Official logo

| File | What it is |
|---|---|
| `EF-logo-ORIGINAL-1024.png` | The supplied logo, byte-for-byte as received (1024×1024). |
| `EF-logo-ORIGINAL-512.png` | The second supplied copy, byte-for-byte (512×512). |
| `EF-logo-endcard-crop.png` | Circular crop of the 1024 original (centre 512,512, radius 415 px, 5 px feather). Pixels inside the circle are untouched: no redraw, recolour, retype, upscale or regeneration. |

The crop exists only because both supplied files are profile-picture screenshots with a grey globe
badge overlapping the lower-right edge of the black disc. The crop radius ends just inside that badge,
so the badge is excluded without retouching anything.

**Two things to check with the brand owner**

1. The wordmark inside the supplied logo reads **“EFstudioLad”** (final letter *d*), while the business
   name is **EF Studio Lab**. The logo was used exactly as supplied, per the brand lock. All text set by
   the campaign itself spells the name “EF Studio Lab”.
2. The supplied file is a low-resolution screenshot. A vector (SVG/PDF) or high-resolution master would
   sharpen every end card; replace `EF-logo-endcard-crop.png` with an 854×854 transparent PNG and re-render.

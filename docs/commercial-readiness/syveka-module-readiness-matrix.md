# Syveka — module readiness matrix (2026-11-08, base `main` = `40f71ae`)

This matrix answers how ready each module is to sell. It uses the readiness states defined
below and the evidence in `syveka-test-evidence.md`.

## Readiness states

- **Code**: the module exists in source.
- **Unit**: automated tests pass. Most are mocked.
- **Integrated**: reachable in the app.
- **E2E**: covered by a Playwright journey.
- **Staging (owner)**: the owner exercised it on staging.
- **Prod**: verified in production.

**No module is verified in production.** Production runs `fc64572` (2026-09-25), 156 commits
behind `main`.

## Launch classifications

Only these classifications are used:

- READY FOR CONTROLLED PILOT
- READY AFTER MINOR FIXES
- BLOCKED BY EXTERNAL VERIFICATION
- PARTIAL IMPLEMENTATION
- EXPERIMENTAL
- DEFER FROM FIRST LAUNCH

"Free pilot" below means the FREE plan plus admin entitlement grants, with no payment
(`docs/free-pilot-launch-runbook.md`, `docs/pilot-entitlement-grants-runbook.md`).

The **Effort** column is a rough engineering estimate, under the assumption that only the
listed work remains. It is not a commitment.

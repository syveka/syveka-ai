## 4. Known limitations and follow-ups (not blocking)

- Dashboard Won/Lost rows count all closed deals (like Analytics); the board shows deals closed in
  the last 30 days. Same label, different windows.
- Admin feature-flag change and its audit row are separate writes (same pattern as entitlement
  grants).
- Assistant replies may contain external https links with any text (XSS-safe; phishing risk if a
  document is prompt-injected). Showing the hostname is a possible follow-up.
- Listen on iOS Safari: speech that starts after the voice wait may be blocked outside the tap;
  untested on a device (Android first).
- No shared accessible dialog primitive in `src/components/ui`; calendar dialogs use their own.
- Some pages outside scope still format times without a zone (Creator Studio, voice calls,
  documents, Business DNA); some system text stays English (voice-call subjects, usage warning).
- Native-speaker review recommended for new Arabic and Finnish copy.
- Local full test run on Windows has the same pre-existing, Windows-only failures as the base
  (path separators, shell self-tests) plus the disclosed intermittent `voice-conversation-flow`;
  CI on Linux is authoritative.
